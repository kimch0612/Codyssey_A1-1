# A1-1 구현 체크리스트 — 쇼핑몰 단골 찾기 (멀티모달 EDA·RFM)

구현 근거는 [Subject.txt](Subject.txt)의 필수 요구사항과 [Evaluate.txt](Evaluate.txt)의 평가 문항이다. 개념 설명은 [Study.md](Study.md)를 참고한다. **보너스 과제는 제외한다.**

Evaluate.txt의 문항에는 번호가 없어서, 이 문서에서는 항목 안의 순서대로 `평가 1-1`~`평가 4-3`으로 부른다(항목 1은 8문항, 항목 2·3은 각 4문항, 항목 4는 3문항). 항목 1은 제출물 점검이므로 1~13단계의 구현 항목에 연결하고, 항목 2~4는 설명 능력을 확인하는 문항이므로 14단계에 연결한다. 전체 대응은 문서 끝의 「평가 항목 연결표」에 있다.

이 과제는 설계를 사용자와 토론해 확정한 뒤 **Claude가 페이즈 단위로 구현하는 방식**으로 진행한다(2026-11-24 사용자 결정, 이 과제에 한정). 페이즈 하나를 구현한 뒤 Claude가 노트북·스크립트를 실행해 동작까지 검증한 항목만 체크하고, 사용자가 승인하기 전에는 다음 페이즈를 시작하지 않는다. 문서를 읽은 것, 설계만 정한 것, 틀만 만든 것은 구현 완료로 표시하지 않는다. 평가 항목 2~4는 사용자가 자신의 말로 설명하는 문항이므로, 각 페이즈가 끝나면 Study.md에 그 페이즈의 구현 설명을 추가한다. 설명 점검(14단계)은 사용자가 설명한 뒤 체크한다.

단계 번호는 의존성 순서이며, 실제 구현은 0-4의 페이즈로 묶어 진행한다. Subject가 지정한 것은 `src/pipeline.py`의 `DataAnalyzer` 클래스와 필수 메서드 4개(`load_data()`, `handle_missing_values()`, `detect_outliers()`, `calculate_rfm()`), `notebooks/analysis_report.ipynb`, `README.md`다. 그 밖의 보조 메서드 이름·개수·노트북 셀 구성은 강제하지 않는다.

시각화와 해석은 여러 단계에 걸쳐 완성된다. 각 단계에서 차트나 해석을 만들었더라도 8단계(시각화 6종)와 12단계(통합 확인) 전에는 해당 요구 전체가 완료된 것이 아니다. 모든 항목은 검증 전 상태로 시작한다.

- [ ] 평가 2-3: 주요 파라미터(이상치 임계값, 결측치 대치 전략, RFM 기준일 등)를 하드코딩하지 않고 인자로 설계한 이유와, 이 설계가 다른 데이터셋에 적용할 때 주는 이점을 설명한다.

### 14-2. 원리 설명 (평가 항목 3)

- [ ] 평가 3-1 (Subject 목표 3): IQR 이상치 탐지가 왜 필요한지, Q1·Q3·IQR로 경계를 계산하는 과정, 어떤 분포에서 효과적이고 어떤 경우에 한계가 있는지(예: 정규분포 vs 비대칭 분포)를 설명하고, 자신의 코드에서 해당 로직을 짚는다. 선택한 임계값과 처리 방식의 이유(D6)도 설명한다.
- [ ] 평가 3-2: 결측치를 그룹별 평균(또는 중앙값)으로 대치하는 이유와, 이 방식이 데이터 분포에 미치는 잠재적 위험(예: 분산 축소, 그룹 간 차이 과장)을 설명한다.
- [ ] 평가 3-3 (Subject 목표 4): RFM 점수 산정 기준(분위수 구간, 스코어링 방식)을 그렇게 정한 이유와, 세분화 결과가 비즈니스적으로 타당하다고 볼 근거를 자신의 데이터에서 뽑아 설명한다.
- [ ] 평가 3-4 (Subject 목표 1): NumPy 벡터 연산이 Python for 반복문보다 빠른 이유를 메모리 구조(연속 메모리 배치)와 연산 방식(SIMD 등) 관점에서 설명한다.
- [ ] Subject 목표 2: 이미지에서 평균·표준편차를 뽑아 수치형 피처로 바꾸는 원리와, 그 값이 이미지의 무엇을 나타내는지 설명한다.

### 14-3. 응용 질문 (평가 항목 4)

평가 항목 4는 파이프라인을 확장했을 때를 묻는 질문이다. 기능을 추가로 구현하라는 뜻이 아니며, 자신의 구현과 결과를 근거로 말로 설명하면 된다.

- [ ] 평가 4-1: 고객 수가 100만 명으로 늘고 이미지 해상도가 1024×1024로 커진다면, 현재 파이프라인에서 가장 먼저 병목이 생기는 지점이 어디이며 어떻게 개선할지 설명한다.
- [ ] 평가 4-2: 이 RFM 분석 결과를 실제 마케팅 캠페인에 적용한다면 가장 먼저 액션을 취할 세그먼트와 그 이유, 전략의 리스크, 이를 검증하기 위해 추가로 필요한 데이터를 설명한다.
- [ ] 평가 4-3: 이 파이프라인을 머신러닝 예측 모델로 확장한다면 어떤 타깃 변수(예: 이탈 여부, 구매 금액)를 설정하고 현재 파이프라인이 만든 피처 중 무엇을 활용할지 설명한다. (Subject 7장이 머신러닝 라이브러리 사용을 금지하므로 이 과제에서는 설명만 한다.)
