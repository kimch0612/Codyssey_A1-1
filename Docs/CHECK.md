# A1-1 구현 체크리스트 — 쇼핑몰 단골 찾기 (멀티모달 EDA·RFM)

구현 근거는 [Subject.txt](Subject.txt)의 필수 요구사항이다. 이 과제에는 `Evaluate.txt`가 없으므로 평가 대비 항목은 Subject 3장 「과제 목표」를 기준으로 삼는다. 개념 설명은 [Study.md](Study.md)를 참고한다. **보너스 과제는 제외한다.**

각 단계에서 필요한 클래스·메서드의 틀을 받은 뒤 세부 내용을 직접 구현한다. 검토 시에는 Git 변경점과 관련 코드를 확인하고, 노트북·스크립트 실행으로 동작까지 검증한 항목만 체크한다. 설명 점검은 자신의 구현과 실행 결과를 근거로 설명한 뒤 체크한다. 문서를 읽거나 틀만 만든 것은 구현 완료로 표시하지 않는다.

단계 번호는 학습을 위한 순서다. Subject가 지정한 것은 `src/pipeline.py`의 `DataAnalyzer` 클래스와 필수 메서드 4개(`load_data()`, `handle_missing_values()`, `detect_outliers()`, `calculate_rfm()`), `notebooks/analysis_report.ipynb`, `README.md`다. 그 밖의 보조 메서드 이름·개수·노트북 셀 구성은 강제하지 않는다.

시각화와 해석은 여러 단계에 걸쳐 완성된다. 각 단계에서 차트나 해석을 만들었더라도 8단계(시각화 6종)와 12단계(통합 확인) 전에는 해당 요구 전체가 완료된 것이 아니다. 모든 항목은 검증 전 상태로 시작한다.
